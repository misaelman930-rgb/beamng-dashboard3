# BeamNG Dashboard (Android)

Оболочка для панели BeamNG Radio: открывает `http://<IP ПК>:8765/digital` во весь экран
и не даёт экрану гаснуть. Телефон и ПК должны быть в одной Wi-Fi сети, а на ПК запущено BeamNG Radio.

## Сборка APK
1. Установите Android Studio (с Android SDK, API 34).
2. File → Open → выберите папку `BeamNGDashboard`. Android Studio сама создаст Gradle wrapper и подтянет зависимости.
3. Build → Build Bundle(s) / APK(s) → Build APK(s).
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`. Скопируйте на телефон и установите
   (разрешите установку из неизвестных источников).

## Использование
При первом запуске введите IP ПК (например `192.168.0.197`). Адрес сохраняется. Кнопка ⚙ в углу меняет его.

## Важно
- APK отладочный (debug), подписан ключом Android Studio. Для публикации в магазине нужна release-сборка и своя подпись.
- Трафик идёт по http внутри локальной сети (разрешено в манифесте).
